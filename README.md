# Prerna Clinic Connect

Build a modern, clean, and responsive single-page clinic website using React and Tailwind CSS for PRERNA CLINIC (Gynaecology and ENT).

Include the following sections:

Hero Section: Clear title, 5.0 Google Star rating badge (3 reviews), address highlight ("Beside City College Of Management, Pasang Lhamu Marg, Nepalgunj"), and two primary CTAs: "Call / WhatsApp for Appointment" and "Get Directions".

Specialties / Services Section: Divide into two distinct categories:

Gynaecology & Obstetrics: Women's Health, Fertility, Antenatal Care, Pregnancy Care.

ENT (Otolaryngology): Ear, Nose, and Throat Diagnostics & Treatment.

Clinic Info & Hours Card: Display address details (Nepalgunj, Lumbini Province 21900), working hours (Closes at 7:00 PM), and peak times (12:00 PM).

Contact & Map Section: Map placeholder, direct booking button, and emergency contact section.

Design Theme: Medical trust theme — soft blues/teals, white background, high contrast text, clean typography, fully mobile-responsive.

2. Direct WhatsApp / Appointment Booking Feature Prompt

Write a lightweight JavaScript/React component for an appointment request form for PRERNA CLINIC. Include fields for Patient Name, Phone Number, Service Needed (Gynaecology or ENT), and Preferred Date. On submission, formatted message text should open directly in WhatsApp targeting the clinic's contact number (+977-9746888888).

3. Local SEO & JSON-LD Structured Data Prompt

Generate a JSON-LD MedicalBusiness schema markup script for a clinic named PRERNA CLINIC (Gynaecology and ENT) located beside City College Of Management, Pasang Lhamu Marg, Nepalgunj, Lumbini Province 21900, Nepal. Include medical specialties (Gynecologic, Otolaryngologic), 5.0 aggregate rating based on 3 reviews, and closing time (19:00).
